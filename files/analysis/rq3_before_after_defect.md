## 2. What LIWC was actually counting

- Correlation between the count of the token `java` and the `emo_sad` word count, across all 300 documents: **r = 0.854**
- Documents containing **no** `java` token (n=163): mean `emo_sad` = **0.32%**
- Documents containing **20 or more** (n=31): mean `emo_sad` = **4.59%**
- Share of those `java` tokens sitting **inside code blocks** in generated Java documents: **90.0%**

# lapx

`lapx` provides Python interfaces for solving cost-matrix assignment problems. Its API accepts NumPy arrays representing costs and returns assignment arrays, optionally together with the resulting total cost.

The library includes:

- Single-problem solvers for dense cost matrices.
- Variants that can extend non-square cost matrices.
- Variants that accept a maximum assignment cost.
- Batch APIs for solving multiple cost matrices at once.
- A sparse/structured entry point, `lapmod`.
- Lower-level helper functions for working with indexed cost data.

## Core concepts

A dense assignment problem is represented by a two-dimensional NumPy array:

```python
cost = np.array([
    [4.0, 1.0, 3.0],
    [2.0, 0.0, 5.0],
    [3.0, 2.0, 2.0],
])
```

Each row and column represents an item to be matched, and `cost[i, j]` is the cost of assigning row `i` to column `j`.

Most single-problem solver functions return either:

```python
total_cost, x, y
```

or, when `return_cost=False`:

```python
x, y
```

The `x` and `y` arrays are the two assignment representations returned by the solver.

Functions whose name ends in `a` return a single assignment array rather than both assignment arrays.

## API overview

### Dense single-problem solvers

| Function | Description |
|---|---|
| `lapjv(cost, extend_cost=False, cost_limit=np.inf, return_cost=True)` | Solve a dense assignment problem, optionally extending the cost matrix or limiting acceptable costs. |
| `lapjvx(cost, extend_cost=False, cost_limit=np.inf, return_cost=True)` | Dense assignment solver with the same public options and return shape as `lapjv`. |
| `lapjvc(cost, return_cost=True)` | Dense assignment solver with a compact parameter set. |
| `lapjvs(cost, extend_cost=None, return_cost=True, jvx_like=True, prefer_float32=True)` | Dense assignment solver with configurable extension behavior and float32 preference. |
| `lapjvsa(cost, extend_cost=None, return_cost=True, prefer_float32=True)` | Single-assignment counterpart to `lapjvs`. |
| `lapjvxa(cost, extend_cost=False, cost_limit=np.inf, return_cost=True)` | Single-assignment counterpart to `lapjvx`. |

The `extend_cost` option is available on several solvers for handling cost matrices that are not naturally square. `cost_limit` is available on `lapjv`, `lapjvx`, and their related APIs when assignments above a specified cost should be constrained.

### Batch solvers

Batch functions accept a NumPy array named `costs` and return results for multiple assignment problems.

| Function | Description |
|---|---|
| `lapjvs_batch(costs, extend_cost=False, return_cost=True, n_threads=0, prefer_float32=True)` | Solve a batch of dense assignment problems. |
| `lapjvsa_batch(costs, extend_cost=False, return_cost=True, n_threads=0, prefer_float32=True)` | Batch solver returning one assignment array per problem. |
| `lapjvx_batch(costs, extend_cost=False, cost_limit=np.inf, return_cost=True, n_threads=0)` | Batch solver with a cost limit. |
| `lapjvxa_batch(costs, extend_cost=False, cost_limit=np.inf, return_cost=True, n_threads=0)` | Single-assignment batch solver with a cost limit. |

When `return_cost=True`, batch APIs return:

```python
costs, assignments_x, assignments_y
```

or, for the `a` variants:

```python
costs, assignments
```

The aggregate costs are returned as a NumPy array, while assignment results are returned as lists of NumPy arrays.

`n_threads=0` leaves thread-count selection to the library.

### Sparse or indexed-cost solver

```python
lapmod(
    n,
    cc,
    ii,
    kk,
    fast=True,
    return_cost=True,
    fp_version=FP_DYNAMIC,
)
```

`lapmod` accepts an explicit problem size plus indexed numeric arrays:

- `n`: problem size.
- `cc`: floating-point cost values.
- `ii`: integer index data.
- `kk`: integer index data.
- `fast`: enable or disable the fast mode.
- `fp_version`: select a floating-point processing version.

Like the dense solvers, `lapmod` returns either:

```python
total_cost, x, y
```

or:

```python
x, y
```

when `return_cost=False`.

### Low-level utilities

The following functions are also available for indexed cost data and path/minimum operations:

```python
find_minima(indices, values)
binary_search(data, key)
find_path(n, cc, ii, kk, start_i, y, v)
check_cost(n, cc, ii, kk)
get_cost(n, cc, ii, kk, x0)
```

These functions operate on generic indexed arrays and are most useful when building workflows around `lapmod`.

## Usage examples

### Solve a single dense assignment problem

```python
import numpy as np
import lapx

cost = np.array([
    [4.0, 1.0, 3.0],
    [2.0, 0.0, 5.0],
    [3.0, 2.0, 2.0],
])

total_cost, x, y = lapx.lapjvx(cost)

print("Total cost:", total_cost)
print("First assignment array:", x)
print("Second assignment array:", y)
```

If the total cost is not needed:

```python
x, y = lapx.lapjvx(cost, return_cost=False)
```

### Request one assignment array

Use an `a` variant when one assignment representation is sufficient:

```python
import numpy as np
import lapx

cost = np.array([
    [8.0, 2.0, 4.0],
    [3.0, 7.0, 1.0],
    [6.0, 5.0, 9.0],
])

total_cost, assignment = lapx.lapjvxa(cost)

print("Total cost:", total_cost)
print("Assignment:", assignment)
```

Or omit the cost:

```python
assignment = lapx.lapjvxa(cost, return_cost=False)
```

### Apply a cost limit

For workflows where assignments should be restricted by a maximum acceptable cost, use `cost_limit`:

```python
import numpy as np
import lapx

cost = np.array([
    [1.0, 100.0, 4.0],
    [2.0, 3.0, 100.0],
    [100.0, 2.0, 1.0],
])

total_cost, x, y = lapx.lapjvx(
    cost,
    cost_limit=10.0,
)

print(total_cost)
print(x)
print(y)
```

### Solve a batch of cost matrices

Provide a collection of cost matrices in a NumPy array:

```python
import numpy as np
import lapx

costs = np.array([
    [
        [4.0, 1.0, 3.0],
        [2.0, 0.0, 5.0],
        [3.0, 2.0, 2.0],
    ],
    [
        [1.0, 4.0, 2.0],
        [3.0, 2.0, 5.0],
        [4.0, 1.0, 3.0],
    ],
])

total_costs, xs, ys = lapx.lapjvx_batch(
    costs,
    n_threads=0,
)

for index, (total_cost, x, y) in enumerate(zip(total_costs, xs, ys)):
    print(f"Problem {index}")
    print("  total cost:", total_cost)
    print("  x:", x)
    print("  y:", y)
```

For a batch where only one assignment array is required:

```python
total_costs, assignments = lapx.lapjvsa_batch(
    costs,
    prefer_float32=True,
)
```

## Choosing a solver

- Use `lapjv`, `lapjvx`, or `lapjvc` for a single dense cost matrix.
- Use `lapjvs` when its `jvx_like` and `prefer_float32` options are useful for your workload.
- Use an `a` suffixed function when only one assignment array is needed.
- Use a `*_batch` function when solving many cost matrices.
- Use `lapjvx` or `lapjv` when `cost_limit` is required.
- Use `lapmod` when your costs are already represented by indexed arrays rather than a dense matrix.

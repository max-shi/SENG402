# torch-sparse

`torch-sparse` provides sparse matrix and graph-oriented tensor operations for PyTorch. Its central abstraction, `SparseTensor`, represents a two-dimensional sparse matrix with optional values and supports COO, CSR, and CSC-style access.

The library includes utilities for:

- Creating sparse tensors from edge indices, dense tensors, PyTorch sparse tensors, and SciPy sparse matrices.
- Converting sparse tensors to dense, PyTorch sparse, and SciPy representations.
- Sparse–dense and sparse–sparse matrix multiplication.
- Reductions, element-wise arithmetic, indexing, selection, concatenation, and transposition.
- Graph-oriented operations such as sampling, random walks, subgraph extraction, partitioning, and node reordering.
- Storage inspection, caching, device movement, dtype conversion, and shared-memory support.

## Core abstraction: `SparseTensor`

`SparseTensor` is the primary matrix container. It stores a sparse two-dimensional structure and, optionally, a value tensor for its non-zero entries.

Common construction methods include:

```python
import torch
from torch_sparse import SparseTensor

# Construct from an edge-index representation:
edge_index = torch.tensor([
    [0, 0, 1, 2],
    [1, 2, 2, 3],
])
edge_weight = torch.tensor([1.0, 2.0, 3.0, 4.0])

adj = SparseTensor.from_edge_index(
    edge_index,
    edge_attr=edge_weight,
    sparse_sizes=(4, 4),
)

# Construct from a dense matrix:
dense = torch.tensor([
    [0.0, 1.0],
    [2.0, 0.0],
])
sparse = SparseTensor.from_dense(dense)

# Create an identity-like sparse matrix:
identity = SparseTensor.eye(4)
```

### Inspecting sparse structure

A `SparseTensor` can expose its structure in multiple layouts:

```python
row, col, value = adj.coo()
rowptr, col, value = adj.csr()
colptr, row, value = adj.csc()

print(adj.sparse_sizes())  # (rows, columns)
print(adj.nnz())           # Number of stored entries
print(adj.density())       # Fraction of stored entries
print(adj.is_coalesced())  # Whether duplicate entries are coalesced
```

Useful shape and sparsity helpers include:

- `sparse_sizes()` / `sparse_size(dim)`
- `sizes()` / `size(dim)` / `dim()`
- `nnz()` / `numel()`
- `density()` / `sparsity()`
- `avg_row_length()` / `avg_col_length()`
- `bandwidth()` / `avg_bandwidth()`
- `is_quadratic()` / `is_symmetric()`

### Converting to other formats

```python
# Dense PyTorch tensor:
dense = adj.to_dense()

# Native PyTorch sparse tensors:
coo_tensor = adj.to_torch_sparse_coo_tensor()
csr_tensor = adj.to_torch_sparse_csr_tensor()
csc_tensor = adj.to_torch_sparse_csc_tensor()

# Construct from native PyTorch sparse tensors:
from_coo = SparseTensor.from_torch_sparse_coo_tensor(coo_tensor)
from_csr = SparseTensor.from_torch_sparse_csr_tensor(csr_tensor)
```

SciPy conversion is also available:

```python
# SparseTensor instance conversion:
scipy_matrix = adj.to_scipy()

# Construction from a SciPy sparse matrix:
restored = SparseTensor.from_scipy(scipy_matrix)
```

## Sparse matrix multiplication

The library provides sparse–dense and sparse–sparse multiplication routines.

### Sparse–dense multiplication

`spmm` multiplies a `SparseTensor` by a dense PyTorch tensor:

```python
import torch
from torch_sparse import SparseTensor, spmm

edge_index = torch.tensor([
    [0, 0, 1, 2],
    [1, 2, 2, 3],
])
edge_weight = torch.tensor([1.0, 1.0, 1.0, 1.0])

adj = SparseTensor.from_edge_index(
    edge_index,
    edge_attr=edge_weight,
    sparse_sizes=(4, 4),
)

# Four nodes with two input features each:
x = torch.tensor([
    [1.0, 0.0],
    [0.0, 1.0],
    [1.0, 1.0],
    [2.0, 1.0],
])

out = spmm(adj, x, reduce='sum')
```

Specialized reduction variants are available:

```python
from torch_sparse import spmm_sum, spmm_mean, spmm_min, spmm_max

summed = spmm_sum(adj, x)
averaged = spmm_mean(adj, x)

minimum, min_index = spmm_min(adj, x)
maximum, max_index = spmm_max(adj, x)
```

### Sparse–sparse multiplication

```python
from torch_sparse import spspmm

two_hop_adj = spspmm(adj, adj, reduce='sum')
```

The lower-level coordinate-based interfaces are also available when working directly with indices and values:

```python
from torch_sparse import spmm as sparse_dense_mm
from torch_sparse import spspmm as sparse_sparse_mm

index = torch.tensor([
    [0, 1, 2],
    [1, 2, 0],
])
value = torch.tensor([1.0, 1.0, 1.0])
features = torch.randn(3, 8)

result = sparse_dense_mm(index, value, m=3, n=3, matrix=features)
```

## Element-wise operations

Sparse tensors can be combined with tensors or scalar-like values through the addition and multiplication APIs:

```python
from torch_sparse import add, add_, add_nnz, mul, mul_, mul_nnz

# Return a new sparse tensor:
shifted = add(adj, 1.0)
scaled = mul(adj, 0.5)

# In-place variants:
add_(adj, 1.0)
mul_(adj, 2.0)

# Operate directly on stored non-zero values:
new_values = torch.ones(adj.nnz())
updated = add_nnz(adj, new_values)
```

`add_nnz` and `mul_nnz` also accept an optional `layout` argument, as do their in-place variants.

## Reductions

Reduce sparse tensors across a dimension or over the whole matrix:

```python
from torch_sparse import sum, mean, min, max

total = sum(adj)
row_sum = sum(adj, dim=1)
column_mean = mean(adj, dim=0)

row_min = min(adj, dim=1)
row_max = max(adj, dim=1)
```

For configurable reduction behavior, use `reduction`:

```python
from torch_sparse import reduction

result = reduction(adj, dim=1, reduce='sum')
```

## Structural transformations

### Transpose and symmetry

```python
from torch_sparse import t

adj_t = t(adj)

if adj.is_quadratic():
    symmetric = adj.to_symmetric(reduce='sum')
```

The coordinate-based transpose function is available for raw sparse indices:

```python
from torch_sparse import transpose

transposed_index, transposed_value = transpose(
    index,
    value,
    m=3,
    n=3,
)
```

### Diagonals

```python
from torch_sparse import get_diag, set_diag, fill_diag, remove_diag

diagonal = get_diag(adj)

with_unit_diagonal = set_diag(adj)
with_custom_diagonal = set_diag(adj, values=torch.ones(4))
with_filled_diagonal = fill_diag(adj, fill_value=1.0)

without_diagonal = remove_diag(adj)
```

All diagonal operations accept an optional offset `k`.

### Selecting, slicing, and reshaping

```python
from torch_sparse import (
    index_select,
    index_select_nnz,
    masked_select,
    masked_select_nnz,
    narrow,
    select,
)

# Select rows or columns using indices:
rows = index_select(adj, dim=0, idx=torch.tensor([0, 2]))
columns = index_select(adj, dim=1, idx=torch.tensor([1, 3]))

# Select one row or column:
row_zero = select(adj, dim=0, idx=0)

# Slice a contiguous range:
first_two_rows = narrow(adj, dim=0, start=0, length=2)

# Select according to a boolean mask:
mask = torch.tensor([True, False, True, False])
masked_rows = masked_select(adj, dim=0, mask=mask)

# Select stored values:
selected_values = index_select_nnz(adj, torch.tensor([0, 2]))
masked_values = masked_select_nnz(
    adj,
    torch.tensor([True, False, True, False]),
)
```

Sparse dimensions can also be changed directly:

```python
adj.sparse_resize((8, 8))
adj.sparse_reshape(num_rows=2, num_cols=16)
```

### Concatenation

```python
from torch_sparse import cat, cat_first, cat_second, cat_diag

a = SparseTensor.eye(2)
b = SparseTensor.eye(2)

# Concatenate along a selected dimension:
combined = cat([a, b], dim=0)

# Explicit structural concatenation helpers:
stacked_first = cat_first([a, b])
stacked_second = cat_second([a, b])
block_diagonal = cat_diag([a, b])
```

## Graph operations

Because an adjacency matrix is naturally represented as a sparse tensor, the library provides several graph-oriented operations.

### Neighbor sampling

```python
from torch_sparse import sample, sample_adj

# Sample neighbors for all rows, or for a supplied subset:
neighbors = sample(adj, num_neighbors=2)

subset = torch.tensor([0, 2])
neighbors = sample(adj, num_neighbors=2, subset=subset)

# Build a sampled adjacency structure:
sampled_adj, sampled_nodes = sample_adj(
    adj,
    subset=subset,
    num_neighbors=2,
    replace=False,
)
```

### Random walks

```python
from torch_sparse import random_walk

start_nodes = torch.tensor([0, 1, 2])
walks = random_walk(adj, start=start_nodes, walk_length=5)
```

### Induced subgraphs

```python
from torch_sparse import saint_subgraph

node_idx = torch.tensor([0, 2, 3])
subgraph, edge_idx = saint_subgraph(adj, node_idx)
```

### Reordering and partitioning

```python
from torch_sparse import permute, reverse_cuthill_mckee, partition

# Apply a node permutation:
perm = torch.tensor([2, 0, 3, 1])
reordered = permute(adj, perm)

# Compute a reverse Cuthill-McKee ordering:
bandwidth_reordered, ordering = reverse_cuthill_mckee(adj)

# Partition a graph:
partitioned, part_ptr, part_perm = partition(
    adj,
    num_parts=2,
    recursive=False,
    weighted=False,
)
```

## Coalescing and coordinate utilities

Coalescing combines duplicate sparse coordinates using a requested reduction operation:

```python
from torch_sparse import coalesce

index = torch.tensor([
    [0, 0, 1],
    [1, 1, 2],
])
value = torch.tensor([1.0, 2.0, 3.0])

coalesced_index, coalesced_value = coalesce(
    index,
    value,
    m=3,
    n=3,
    op='add',
)
```

For `SparseTensor` objects:

```python
coalesced_adj = adj.coalesce(reduce='sum')
```

Other coordinate utilities include:

```python
from torch_sparse import spadd, index_sort

# Add two coordinate-format sparse matrices:
index_out, value_out = spadd(
    indexA,
    valueA,
    indexB,
    valueB,
    m=3,
    n=3,
)

# Sort index values and obtain the corresponding permutation:
sorted_values, permutation = index_sort(torch.tensor([3, 1, 2]))
```

## Storage and value management

`SparseTensor` exposes operations for updating or removing values without changing the sparse structure:

```python
# Replace stored values:
new_values = torch.randn(adj.nnz())
adj.set_value_(new_values)

# Return a new tensor with replacement values:
updated = adj.set_value(new_values)

# Fill all stored values:
adj.fill_value_(fill_value=1.0)

# Remove stored values:
structure_only = adj.set_value(None)
```

The associated `SparseStorage` abstraction provides lower-level access to sparse structural data, including row pointers, column pointers, row and column counts, cached layout conversions, and storage copying.

## Device, dtype, and autograd support

Sparse tensors support common PyTorch-style device and dtype operations:

```python
adj = adj.cpu()
adj = adj.cuda()

adj = adj.float()
adj = adj.double()
adj = adj.bool()

adj = adj.to(dtype=torch.float32)
adj = adj.to(device='cuda')

adj.requires_grad_(True)
assert adj.requires_grad()

detached = adj.detach()
```

Memory helpers are available as well:

```python
adj = adj.pin_memory()
is_pinned = adj.is_pinned()

adj.share_memory_()
is_shared = adj.is_shared()
```

## Format conversion helpers

The package also provides conversion functions for coordinate-format sparse matrices:

```python
from torch_sparse import to_torch_sparse, from_torch_sparse
from torch_sparse import to_scipy, from_scipy

torch_sparse_tensor = to_torch_sparse(index, value, m=3, n=3)
index, value, m, n = from_torch_sparse(torch_sparse_tensor)

scipy_sparse_matrix = to_scipy(index, value, m=3, n=3)
index, value, m, n = from_scipy(scipy_sparse_matrix)
```

## Identity matrices

For a simple sparse identity matrix:

```python
from torch_sparse import eye

identity = eye(5)
```

For a rectangular identity-like matrix, use `SparseTensor.eye`:

```python
rectangular_identity = SparseTensor.eye(M=3, N=5)
```

# pygelf

`pygelf` provides utilities and logging handlers for producing GELF-style log messages. It can:

- Convert logging records into GELF message structures.
- Add fields from a record to a GELF message.
- Serialize and pack messages, optionally with compression.
- Split messages into chunks for transport.
- Send logging records through TCP, UDP, TLS, HTTP, or HTTPS-oriented handlers.

## Overview

The library is organized around two complementary pieces:

1. **GELF message utilities**  
   Functions for building, enriching, serializing, packing, and splitting GELF messages.

2. **Logging handlers**  
   Handler classes that convert Python logging records to GELF and send them through different transport mechanisms.

## GELF Utilities

### `make`

```python
make(
    record,
    domain,
    debug,
    version,
    additional_fields,
    additional_env_fields,
    include_extra_fields=False,
)
```

Creates a GELF message from a logging record.

The function accepts metadata such as:

- `domain`
- `debug`
- `version`
- `additional_fields`
- `additional_env_fields`

Set `include_extra_fields=True` to include extra fields attached to the logging record.

### `add_extra_fields`

```python
add_extra_fields(gelf, record)
```

Adds fields from a logging record to an existing GELF message.

Use this when a GELF message has already been created and needs to be enriched with record-specific data.

### `object_to_json`

```python
object_to_json(obj)
```

Converts an object into a JSON-compatible representation.

This can be useful when GELF fields contain values that are not directly JSON serializable.

### `pack`

```python
pack(gelf, compress, default)
```

Serializes a GELF message into a transportable representation.

- `compress` controls whether packing should use compression.
- `default` supplies conversion behavior for values that require custom JSON handling.

### `split`

```python
split(gelf, chunk_size)
```

Splits a GELF message into chunks of the requested size. This is useful when a transport has message-size limits.

## Logging Handlers

All handler implementations derive from `BaseHandler`.

### `BaseHandler`

```python
class BaseHandler:
    def convert_record_to_gelf(self, record):
        ...
```

`BaseHandler` provides conversion from a logging record to a GELF message.

### `GelfTcpHandler`

```python
class GelfTcpHandler(BaseHandler, SocketHandler):
    def makePickle(self, record):
        ...
```

A TCP-oriented logging handler. Its `makePickle()` implementation prepares a logging record for transmission after GELF conversion.

### `GelfUdpHandler`

```python
class GelfUdpHandler(BaseHandler, DatagramHandler):
    def send(self, s):
        ...
    def makePickle(self, record):
        ...
```

A UDP-oriented logging handler.

- `makePickle()` prepares a record for sending.
- `send()` transmits the resulting data.

UDP transports often require message chunking, making the `split()` helper relevant when working with size-limited datagrams.

### `GelfTlsHandler`

```python
class GelfTlsHandler(GelfTcpHandler):
    def makeSocket(self, timeout=1):
        ...
```

A TLS-enabled variant of the TCP handler.

Its `makeSocket()` method creates the socket used for the connection and accepts an optional timeout.

### `GelfHttpHandler`

```python
class GelfHttpHandler(BaseHandler, LoggingHandler):
    def emit(self, record):
        ...
```

An HTTP-oriented logging handler. Calling `emit()` processes and sends a logging record.

### `GelfHttpsHandler`

```python
class GelfHttpsHandler(BaseHandler, LoggingHandler):
    def emit(self, record):
        ...
```

An HTTPS-oriented logging handler. Like `GelfHttpHandler`, it emits logging records after converting them to GELF.

## Usage

### Build and pack a GELF message

The following example creates a standard Python logging record, turns it into a GELF message, and packs it for transport.

```python
import logging

from pygelf.gelf import make, object_to_json, pack

record = logging.LogRecord(
    name="my_application",
    level=logging.INFO,
    pathname=__file__,
    lineno=42,
    msg="User signed in",
    args=(),
    exc_info=None,
)

record.user_id = 123
record.request_id = "req-9fdb"

gelf_message = make(
    record=record,
    domain="example.org",
    debug=False,
    version="1.1",
    additional_fields={
        "service": "accounts",
        "environment": "production",
    },
    additional_env_fields={},
    include_extra_fields=True,
)

payload = pack(
    gelf=gelf_message,
    compress=True,
    default=object_to_json,
)
```

### Add extra fields to an existing message

```python
import logging

from pygelf.gelf import add_extra_fields, make

record = logging.LogRecord(
    name="worker",
    level=logging.WARNING,
    pathname=__file__,
    lineno=18,
    msg="Retrying task",
    args=(),
    exc_info=None,
)

record.task_id = "task-4815"
record.retry_count = 2

gelf_message = make(
    record=record,
    domain="example.org",
    debug=False,
    version="1.1",
    additional_fields={"service": "worker"},
    additional_env_fields={},
)

add_extra_fields(gelf_message, record)
```

### Split a message into chunks

For transports where individual messages must remain below a size limit, split the GELF message into smaller pieces.

```python
from pygelf.gelf import split

chunks = split(
    gelf=gelf_message,
    chunk_size=1400,
)

for chunk in chunks:
    # Send each chunk using the transport of your choice.
    pass
```

### Integrate a handler with `logging`

The handler classes are intended to participate in Python's logging system. Choose a handler based on the destination transport:

- `GelfTcpHandler` for TCP delivery.
- `GelfUdpHandler` for UDP delivery.
- `GelfTlsHandler` for TLS-protected TCP delivery.
- `GelfHttpHandler` for HTTP delivery.
- `GelfHttpsHandler` for HTTPS delivery.

Once configured, attach the handler to a logger:

```python
import logging

logger = logging.getLogger("my_application")
logger.setLevel(logging.INFO)

# Create and configure an appropriate pygelf handler for your destination.
handler = ...

logger.addHandler(handler)

logger.info(
    "Application started",
    extra={
        "service": "api",
        "release": "2025.03",
    },
)
```

When the logger emits a record, the selected handler converts it to GELF and sends it through its configured transport.

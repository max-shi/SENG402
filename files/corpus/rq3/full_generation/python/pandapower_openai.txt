# pandapower

`pandapower` is a Python library for building, analyzing, converting, validating, visualizing, and operating electrical power-network models.

The central network object is `pandapowerNet`, a dictionary-like container holding network element tables, configuration, and calculation results. The API provides functions to create buses, lines, transformers, loads, generators, converters, shunts, storage systems, measurements, costs, and groups; then run power flow, optimal power flow, short-circuit calculations, state estimation, time-series studies, contingency studies, protection calculations, and more.

## Highlights

- Build AC and DC power networks programmatically.
- Model buses, lines, transformers, loads, generators, external grids, shunts, storage, converter systems, and impedance elements.
- Run AC power flow, DC power flow, three-phase power flow, and optimal power flow.
- Perform short-circuit calculations and protection studies.
- Estimate network states from measurements.
- Execute time-series simulations with controllers and output writers.
- Run N-1 contingency evaluations, including parallel execution.
- Import and export several network formats.
- Create static or interactive visualizations.
- Analyze connectivity and network topology.
- Validate, diagnose, compare, modify, serialize, and persist networks.

## Core workflow

A typical workflow is:

1. Create an empty network with `create_empty_network`.
2. Add buses and network elements using functions from the creation API.
3. Run a calculation such as `runpp`, `rundcpp`, `runopp`, or `calc_sc`.
4. Inspect result tables stored in the network.
5. Optionally diagnose, plot, export, or modify the network.

```python
from pandapower.create.network_create import create_empty_network
from pandapower.create.bus_create import create_bus
from pandapower.create.ext_grid_create import create_ext_grid
from pandapower.create.line_create import create_line_from_parameters
from pandapower.create.load_create import create_load
from pandapower.run import runpp

net = create_empty_network(name="simple feeder", f_hz=50.0, sn_mva=1.0)

slack_bus = create_bus(net, vn_kv=20.0, name="Grid connection")
load_bus = create_bus(net, vn_kv=20.0, name="Load bus")

create_ext_grid(net, bus=slack_bus, vm_pu=1.0, name="Upstream grid")

create_line_from_parameters(
    net,
    from_bus=slack_bus,
    to_bus=load_bus,
    length_km=2.0,
    r_ohm_per_km=0.25,
    x_ohm_per_km=0.10,
    c_nf_per_km=10.0,
    max_i_ka=0.30,
    name="Feeder",
)

create_load(
    net,
    bus=load_bus,
    p_mw=0.50,
    q_mvar=0.15,
    name="Demand",
)

runpp(net)

# Calculation results are available in the network result tables.
print(net["res_bus"])
print(net["res_line"])
```

## Network model

### `pandapowerNet`

`pandapowerNet` is the main network container. It extends `ADict`, which is a mutable dictionary-like type. It is used as the first argument of most creation, calculation, conversion, and utility functions.

Create a new network with:

```python
from pandapower.create.network_create import create_empty_network

net = create_empty_network(
    name="My network",
    f_hz=50.0,
    sn_mva=1.0,
    add_stdtypes=True,
)
```

### Buses

Buses represent AC and DC electrical nodes.

```python
from pandapower.create.bus_create import (
    create_bus,
    create_buses,
    create_bus_dc,
    create_buses_dc,
)

bus = create_bus(net, vn_kv=110.0, name="HV bus")
buses = create_buses(net, nr_buses=3, vn_kv=20.0)

dc_bus = create_bus_dc(net, vn_kv=320.0, name="DC bus")
```

Bus creation supports optional names, indices, zones, coordinates, voltage limits, service status, and custom columns through `**kwargs`.

### Lines and DC lines

Use a standard type or directly supply electrical parameters.

```python
from pandapower.create.line_create import (
    create_line,
    create_line_from_parameters,
    create_dcline,
)

# Line based on a standard type available in the network:
line_a = create_line(
    net,
    from_bus=0,
    to_bus=1,
    length_km=1.5,
    std_type="example line type",
)

# Line with explicit electrical parameters:
line_b = create_line_from_parameters(
    net,
    from_bus=1,
    to_bus=2,
    length_km=0.8,
    r_ohm_per_km=0.20,
    x_ohm_per_km=0.08,
    c_nf_per_km=12.0,
    max_i_ka=0.25,
)

# HVDC link between AC buses:
dc_link = create_dcline(
    net,
    from_bus=0,
    to_bus=2,
    p_mw=10.0,
    loss_percent=1.0,
    loss_mw=0.0,
    vm_from_pu=1.0,
    vm_to_pu=1.0,
)
```

For vectorized model construction, use `create_lines`, `create_lines_from_parameters`, `create_lines_dc`, and `create_lines_dc_from_parameters`.


## Power-flow and optimization calculations

### AC power flow

Use `runpp` for AC power flow.

```python
from pandapower.run import runpp

runpp(
    net,
    algorithm="nr",
    calculate_voltage_angles=True,
    init="auto",
    max_iteration="auto",
    tolerance_mva=1e-8,
    trafo_model="t",
    trafo_loading="current",
    enforce_q_lims=False,
    check_connectivity=True,
    voltage_depend_loads=True,
)
```

`runpp` also supports options for controller execution, distributed slack, temperature-dependent power flow, line temperatures, and additional keyword options.

The following exceptions identify non-convergent or unsupported calculations:

- `LoadflowNotConverged`
- `OPFNotConverged`
- `ControllerNotConverged`
- `NetCalculationNotConverged`
- `AlgorithmUnknown`

### DC and three-phase power flow

```python
from pandapower.run import rundcpp
from pandapower.pf.runpp_3ph import runpp_3ph

rundcpp(net)

runpp_3ph(
    net,
    calculate_voltage_angles=True,
    init="auto",
    trafo_model="t",
    trafo_loading="current",
)
```

### Optimal power flow

`runopp` performs optimal power flow, while `rundcopp` provides a DC optimal-power-flow entry point.

```python
from pandapower.create.cost_create import create_poly_cost
from pandapower.run import runopp

create_poly_cost(
    net,
    element=0,
    et="gen",
    cp1_eur_per_mw=40.0,
    cp0_eur=100.0,
    min_q_mvar=-3.0,
    max_q_mvar=3.0,
)

runopp(net, calculate_voltage_angles=True)
```

Cost functions can be added with:

- `create_poly_cost`, `create_poly_costs`
- `create_pwl_cost`, `create_pwl_costs`

## State estimation

Measurements can be added with `create_measurement`, then passed to the estimation API.

```python
from pandapower.create.measurement_create import create_measurement
from pandapower.estimation.state_estimation import estimate

create_measurement(
    net,
    meas_type="v",
    element_type="bus",
    element=0,
    value=1.01,
    std_dev=0.01,
    name="Voltage measurement at bus 0",
)

create_measurement(
    net,
    meas_type="p",
    element_type="line",
    element=0,
    side="from",
    value=0.45,
    std_dev=0.03,
)

success = estimate(
    net,
    algorithm="wls",
    init="flat",
    tolerance=1e-6,
    maximum_iterations=50,
    zero_injection="aux_bus",
)
```

Additional state-estimation tools include:

- `remove_bad_data`
- `chi2_analysis`
- `estimate_voltage_vector`
- `add_virtual_meas_from_loadflow`
- `add_virtual_pmu_meas_from_loadflow`
- `add_virtual_meas_error`
- `set_bb_switch_impedance`
- `reset_bb_switch_impedance`

The `StateEstimation` class offers an object-oriented interface for estimation, chi-squared testing, and residual-based tests.

## Short-circuit analysis and protection

### Short-circuit calculation

Use `calc_sc` to calculate short-circuit conditions.

```python
from pandapower.shortcircuit.calc_sc import calc_sc

calc_sc(
    net,
    bus=None,
    fault="3ph",
    case="max",
    lv_tol_percent=10,
    ip=True,
    ith=True,
    branch_results=True,
)
```

Line-specific short-circuit studies are available through `calc_sc_on_line`.

### Protection studies

Protection devices derive from `ProtectionDevice`. Available device classes include `Fuse` and `OCRelay`.

```python
from pandapower.protection.run_protection import calculate_protection_times

trip_decisions = calculate_protection_times(net, scenario="sc")
```

Useful protection utilities include:

- `calc_faults_at_full_line`
- `plot_tripped_grid`
- `plot_tripped_grid_protection_device`
- `get_lowest_impedance_line`
- `get_vi_angle`
- `time_grading`

## Controllers and time series

Controllers are represented by the `BasicCtrl` and `Controller` base classes. The API includes controller types for constant values, characteristics, DER operation, transformer taps, shunts, station controls, and droop controls.

Notable controller classes include:

- `ConstControl`
- `CharacteristicControl`
- `DERController`
- `PQController`
- `ContinuousTapControl`
- `DiscreteTapControl`
- `TapDependentImpedance`
- `ShuntController`
- `DiscreteShuntController`
- `BinarySearchControl`
- `DroopControl`
- `VDroopControl_local`

The control loop can be run directly:

```python
from pandapower.control.run_control import run_control

run_control(net, max_iter=30)
```

For time-series simulations, provide controllers and optionally an output writer, then call `run_timeseries`.

```python
from pandapower.timeseries.run_time_series import run_timeseries

run_timeseries(
    net,
    time_steps=range(24),
    continue_on_divergence=False,
    verbose=True,
)
```

Time-series support includes:

- `DataSource` and `DFData` for profile data
- `OutputWriter` for result logging
- `init_default_outputwriter`
- `init_output_writer`
- `run_time_step`
- `run_timeseries`
- `TimeSeriesRunpp`

## Contingency analysis

Use `run_contingency` to evaluate a network under N-1 cases. A contingency case definition is passed as `nminus1_cases`.

```python
from pandapower.contingency.contingency import run_contingency

results = run_contingency(
    net,
    nminus1_cases=nminus1_cases,
    pf_options={"calculate_voltage_angles": True},
    pf_options_nminus1={"calculate_voltage_angles": True},
    write_to_net=True,
)
```

Additional contingency functions include:

- `run_contingency_ls2g`
- `run_contingency_parallel`
- `get_element_limits`
- `check_elements_within_limits`
- `report_contingency_results`

## Groups

Groups associate multiple network elements under one logical identifier.

```python
from pandapower.create.group_create import create_group
from pandapower.groups import (
    group_name,
    group_res_p_mw,
    set_group_out_of_service,
)

group = create_group(
    net,
    element_types=["line", "load"],
    element_indices=[[0, 1], [0, 1, 2]],
    name="Feeder A",
)

print(group_name(net, group))
print(group_res_p_mw(net, group))

set_group_out_of_service(net, group)
```

Group utilities support attaching and detaching elements, comparing groups, checking membership, setting values, collecting result powers, and producing a network for a group.

## Import, export, and serialization

### File formats

The API supports serializing and loading networks through pickle, Excel, and JSON.

```python
from pandapower.file_io import (
    to_json,
    from_json,
    to_excel,
    from_excel,
)

to_json(net, "network.json")
to_excel(net, "network.xlsx", include_results=True)

net_from_json = from_json("network.json")
net_from_excel = from_excel("network.xlsx")
```

`to_json` can also return a JSON string when no filename is supplied.

### SQL persistence

```python
from pandapower.sql_io import to_sqlite, from_sqlite

to_sqlite(net, "network.sqlite", include_results=True)
loaded_net = from_sqlite("network.sqlite")
```

PostgreSQL-oriented functions are also available through `to_postgresql`, `from_postgresql`, `to_sql`, and `from_sql`.

### Converters

The converter API includes interfaces for multiple external formats and systems:

- CIM: `from_cim`, `from_cim_dict`
- MATPOWER-style case data: `from_mpc`, `to_mpc`
- PYPOWER case data: `from_ppc`, `to_ppc`
- OpenDSS: `from_opendss`
- UCTE: `from_ucte`, `from_ucte_dict`
- JAO input: `from_jao`
- PowerFactory export/import helpers: `from_pfd`, `from_pf`
- PowerModels conversion: `convert_pp_to_pm`, `convert_to_pm_structure`

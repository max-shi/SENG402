# web-fragments

`web-fragments` provides building blocks for representing reusable HTML fragments together with the resources they require, such as CSS and JavaScript.

A fragment can collect body content, inline or URL-based resources, and JavaScript initialization calls. It can then render its content and resources separately for document body, head, and footer placement. The library also includes a Django view base class for serving fragments or rendering them as standalone pages.

## Overview

The main pieces are:

- **`Fragment`** — a container for HTML content and associated resources.
- **`FragmentView`** — a Django `View` subclass for rendering fragments in HTTP responses.
- **`WebFragmentsConfig`** — the Django application configuration class.

Typical usage looks like this:

1. Create a `Fragment`.
2. Add HTML content.
3. Add CSS, JavaScript, or other resources.
4. Render the fragment’s body and resource HTML, or return it from a `FragmentView`.

## Installation

Install the package using your preferred Python package management workflow, then add the application configuration to your Django project if required by your project setup.

## Creating fragments

Create a `Fragment` and add HTML content with `add_content()`:

```python
from web_fragments.fragment import Fragment

fragment = Fragment()
fragment.add_content("""
<section class="welcome">
  <h1>Welcome</h1>
  <p>This content was generated by a fragment.</p>
</section>
""")
```

Render the fragment body:

```python
html = fragment.body_html()
```

## Adding resources

Fragments can include inline resources or external resource URLs.

### CSS

Add inline CSS:

```python
fragment.add_css("""
.welcome {
  padding: 1rem;
  border-radius: 0.5rem;
  background: #f5f5f5;
}
""")
```

Add CSS from a URL:

```python
fragment.add_css_url("https://cdn.example.test/site.css")
```

### JavaScript

Add inline JavaScript:

```python
fragment.add_javascript("""
console.log("Fragment resources loaded");
""")
```

Add JavaScript from a URL:

```python
fragment.add_javascript_url("https://cdn.example.test/widget.js")
```

### Generic resources

For resource types beyond the CSS and JavaScript helpers, use `add_resource()` or `add_resource_url()` and provide a MIME type:

```python
fragment.add_resource(
    "<svg><!-- inline SVG resource --></svg>",
    mimetype="image/svg+xml",
)

fragment.add_resource_url(
    "https://cdn.example.test/icon.svg",
    mimetype="image/svg+xml",
)
```

Both generic resource methods accept an optional `placement` argument. Resource placement determines where the resource is rendered when producing HTML for a particular page area.

```python
fragment.add_resource(
    "/* additional styles */",
    mimetype="text/css",
    placement="head",
)
```

## Rendering fragment HTML

`Fragment` exposes separate rendering methods for different sections of an HTML document:

```python
body = fragment.body_html()
head = fragment.head_html()
foot = fragment.foot_html()
```

These can be assembled into a full document:

```python
page_html = f"""<!doctype html>
<html>
  <head>
    {fragment.head_html()}
  </head>
  <body>
    {fragment.body_html()}
    {fragment.foot_html()}
  </body>
</html>
"""
```

To render resources for a particular placement directly, use `resources_to_html()`:

```python
head_resources = fragment.resources_to_html("head")
```

Individual resource objects can be converted to HTML with `Fragment.resource_to_html()` when working with resources returned by `resources()`.

```python
for resource in fragment.resources():
    resource_html = Fragment.resource_to_html(resource)
```

## Initializing JavaScript

Use `initialize_js()` to register a JavaScript function call for the fragment. Optional JSON-compatible arguments may be supplied through `json_args`.

```python
fragment.initialize_js(
    "initializeWelcomeWidget",
    json_args={
        "userName": "Ada",
        "showGreeting": True,
    },
)
```

This is useful when a fragment’s JavaScript needs data produced by the server.

## Combining fragments

A fragment can include the resources required by another fragment.

Use `add_fragment_resources()` when adding resources from one fragment:

```python
profile_fragment = Fragment()
profile_fragment.add_content("<div class='profile'>Profile</div>")
profile_fragment.add_css(".profile { font-weight: bold; }")

page_fragment = Fragment()
page_fragment.add_content("<main>...</main>")
page_fragment.add_fragment_resources(profile_fragment)
```

Use `add_resources()` to collect resources from multiple fragments:

```python
header = Fragment()
header.add_css(".header { background: navy; }")

footer = Fragment()
footer.add_javascript("console.log('footer loaded')")

page_fragment = Fragment()
page_fragment.add_resources([header, footer])
```

This allows a page-level fragment to gather the dependencies of all fragments it includes.

## Serializing fragments

Fragments can be converted to a dictionary representation and reconstructed later:

```python
fragment = Fragment()
fragment.add_content("<p>Saved fragment content</p>")
fragment.add_css("p { color: rebeccapurple; }")

data = fragment.to_dict()

restored = Fragment.from_dict(data)
```

This can be useful when fragment data needs to cross process boundaries or be stored in a serializable form.

## Django views

`FragmentView` is a Django `View` base class intended for endpoints that render fragments.

Subclass it and provide `render_to_fragment()` to create the fragment for a request:

```python
from web_fragments.fragment import Fragment
from web_fragments.views import FragmentView


class WelcomeView(FragmentView):
    def render_to_fragment(self, request, **kwargs):
        fragment = Fragment()

        fragment.add_content("""
        <section class="welcome">
          <h1>Welcome!</h1>
          <p>Rendered from a FragmentView.</p>
        </section>
        """)

        fragment.add_css("""
        .welcome {
          max-width: 40rem;
          margin: 2rem auto;
        }
        """)

        fragment.initialize_js(
            "initializeWelcomeWidget",
            json_args={"enabled": True},
        )

        return fragment
```

Attach the view to a Django URL pattern in the usual way:

```python
from django.urls import path

urlpatterns = [
    path("welcome/", WelcomeView.as_view(), name="welcome"),
]
```

`FragmentView` provides:

- `get(request, *args, **kwargs)` for handling GET requests.
- `render_to_fragment(request, **kwargs)` for producing the fragment associated with a request.
- `render_to_standalone_html(request, fragment, **kwargs)` for producing standalone HTML from a fragment.
- `render_standalone_response(request, fragment, **kwargs)` for producing a standalone response.

A view can override the standalone rendering methods when an application needs custom page wrapping or response behavior.

```python
class CustomWelcomeView(WelcomeView):
    def render_to_standalone_html(self, request, fragment, **kwargs):
        return f"""<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Welcome</title>
    {fragment.head_html()}
  </head>
  <body>
    {fragment.body_html()}
    {fragment.foot_html()}
  </body>
</html>
"""
```

## API summary

### `Fragment`

| Method | Purpose |
| --- | --- |
| `resources()` | Return the fragment’s collected resources. |
| `to_dict()` | Convert the fragment to a dictionary representation. |
| `from_dict(pods)` | Create a fragment from a dictionary representation. |
| `add_content(content)` | Add content to the fragment. |
| `add_resource(text, mimetype, placement=None)` | Add an inline resource. |
| `add_resource_url(url, mimetype, placement=None)` | Add an external resource URL. |
| `add_css(text)` | Add inline CSS. |
| `add_css_url(url)` | Add CSS from a URL. |
| `add_javascript(text)` | Add inline JavaScript. |
| `add_javascript_url(url)` | Add JavaScript from a URL. |
| `add_fragment_resources(fragment)` | Add resources from another fragment. |
| `add_resources(fragments)` | Add resources from multiple fragments. |
| `initialize_js(js_func, json_args=None)` | Register JavaScript initialization for the fragment. |
| `body_html()` | Render fragment body HTML. |
| `head_html()` | Render HTML intended for the document head. |
| `foot_html()` | Render HTML intended for the document footer area. |
| `resources_to_html(placement)` | Render resources for a placement. |
| `resource_to_html(resource)` | Render a single resource as HTML. |

### `FragmentView`

| Method | Purpose |
| --- | --- |
| `get(request, *args, **kwargs)` | Handle a GET request. |
| `render_to_fragment(request, **kwargs)` | Build a fragment for a request. |
| `render_to_standalone_html(request, fragment, **kwargs)` | Render a fragment as standalone HTML. |
| `render_standalone_response(request, fragment, **kwargs)` | Produce a standalone response for a fragment. |
